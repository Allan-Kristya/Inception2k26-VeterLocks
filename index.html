      Tentang LaporAman
      

      Platform pelaporan publik cerdas dari UPN “Veteran” Jawa Timur: efektif, efisien, transparan, aman, inklusif, dan terpercaya.
      

      

      Triase cerdas
      Klasifikasi multilabel lintas sektor dengan skor keyakinan. Keyakinan di bawah 70% masuk antrean tinjauan petugas (human-in-the-loop).
      

      Zero-Knowledge dan E2EE
      Identitas, detail sensitif, dan lampiran dienkripsi di perangkat dengan PBKDF2 dan AES-256-GCM. Server hanya menerima ciphertext.
      

      Aksesibilitas WCAG 2.1 AA
      Kontras tinggi, zoom teks hingga 200%, label ARIA, navigasi keyboard, dikte suara, dan perintah suara.
      

      Interoperabilitas SPBE
      REST API dengan spesifikasi OpenAPI 3.1.0, webhook, gateway, dan isolasi data antarwilayah.
